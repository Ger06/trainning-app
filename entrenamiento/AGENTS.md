# AGENTS.md — <entrenamiento>

## Proyecto
Entrenamiento es una plataforma para que entrenadores puedan armar rutinas de ejercicios personalizadas, y que los alumnos puedan consultarlas. Voy a trabajar con Next.js, shadcn, vitest y MongoDB

## Comandos
- Ejecutar: `npm run dev`
- Test unitarios: `npm run test:unit`
- Test de integración: `npm run test:integration`

## Estilo y convenciones
- Next: 16.3.0
- Test unitarios y de integración.

## Reglas
- Lee docs/constitution.md y la spec activa en specs/ antes de tocar código.
- No añadas dependencias ni cambies el formato del JSON sin actualizar antes la spec.
- No modifiques archivos dentro de specs/ salvo petición explícita.

## Al terminar cualquier tarea
- Ejecuta npm run test y confirma en tu respuesta que todo pasa
